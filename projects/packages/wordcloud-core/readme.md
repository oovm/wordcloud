# @doki-land/wordcloud-core

Shared TypeScript core types and contracts for [`@doki-land/wordcloud`](../wordcloud).

```ts
import type { LayoutConfig, WordCloudElement, WordFrequency } from "@doki-land/wordcloud-core";
```

Use this package when you only need types (homepage, adapters, tests) without pulling in the layout engine or custom element.
