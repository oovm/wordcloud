# wordcloud-benchmark

**Workspace-only** benchmarks for `@doki-land/wordcloud-layout` and `@doki-land/wordcloud-renderer`.  
This package is `private: true` and is **not** published to npm.

```bash
# from repo root
pnpm bench

# or inside this package
pnpm bench:layout
pnpm bench:renderer
```

Outputs median milliseconds per iteration to stdout.
